# R-Universe Locked Finite-Window Theory

Standalone locked finite-window calibration theory of geometry and cosmic expansion.

## Structure

- `main.tex` — manuscript source.
- `graf.tex` — figure inclusion block, using `figures/` paths.
- `references.bib` — bibliography.
- `figures/` — generated figure assets.
- `code/locked_r_universe.py` — direct integration of the locked finite-window equations.
- `code/locked_r_universe_results.json` — machine-readable result.
- `code/run_all.py` — reproduction plus static audit.
- `tables/locked_r_universe_background.csv` — sampled background branch.

## Reproduce

```bash
python3 code/run_all.py
```
