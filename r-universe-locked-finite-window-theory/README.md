# R-Universe locked finite-window no-go package

This package accompanies the manuscript:

**R-Universe: A Locked Finite-Window Calibration Theory of Geometry and Cosmic Expansion**

## Main result

This release tests one specific local realization of the R-Universe finite-window idea: a trace-sourced scalar calibration field imposed by a hard Lagrange multiplier.

The tested localization is

```text
(1 - ell^2 Box) R_c = -T / M_Pl^2
```

After integration by parts, the scalar kinetic Hessian in the field velocities `(Rdot_c, lambdadot)` is

```text
K = [[Z(R_c), ell^2],
     [ell^2,  0    ]]
```

so

```text
det K = -ell^4.
```

For any finite nonzero `ell`, the homogeneous Hessian has an indefinite signature. Including the positive scalar kinetic contribution generated by the non-minimal `F(R_c) R` term changes the upper-left entry, but the Einstein-frame determinant remains

```text
det K_E = -ell^4 / F^2 < 0
```

for `F > 0`.

The conclusion is therefore a no-go result for this hard Lagrange-multiplier localization. It is not a disproof of the finite-window principle itself.

## Important scope limits

- The action calibrates the trace `T`, not the full tensor `T_munu`.
- The retarded branch is a physical boundary-condition choice; it is not selected by the single-copy local action alone.
- The reduced background branch is diagnostic only. It omits the multiplier stress tensor and the matter-variation terms induced by `lambda T`.
- The perturbation formulae in the manuscript are templates for a future healthy one-scalar successor theory, not predictions of the failed multiplier action.
- A final theorem for the full metric-scalar system still requires an ADM reduction with lapse and shift eliminated.
