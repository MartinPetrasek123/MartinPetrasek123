# GR Planck 2018 Low-Ell And Lensing Reference

This is an executed likelihood evaluation of the official Planck low-T, low-E and lensing components at a fixed GR/CAMB reference point. It is not an RFG-R likelihood, posterior, best fit, or model comparison.

The likelihood uses a BBN-consistent helium fraction from Cobaya's standard one-heavy-neutrino Planck preset and the defined nominal calibration A_planck=1. The high-ell Plik likelihood is installed but not evaluated here, because its foreground and calibration parameters have not been fitted.

Combined log likelihood: -2.141707543093e+02
Combined -2 log likelihood: 4.283415086187e+02
